根据知识库资料，Spark 性能调优需要关注以下几个方面：

1. Executor 内存配置[1]建议设置为 4-8GB

2. 并行度设置[2]应该是 CPU 核心数的 2-3 倍

3. 数据倾斜处理[3]可以使用加盐技术

参考来源
[1] …> 资源配置 > executor memory 展开原文
Executor 内存是 Spark 作业性能的关键参数。建议根据数据量和计算复杂度，将 executor-memory 设置为 4-8GB。过小会导致频繁的 GC，过大会浪费集群资源。
[2] …> 并行度配置 展开原文
Spark 的并行度（spark.default.parallelism）应该设置为 CPU 核心总数的 2-3 倍，以充分利用集群资源。对于 shuffle 操作，还需要设置 spark.sql.shuffle.partitions。
[3] …> 常见问题 > 数据倾斜 展开原文
数据倾斜是 Spark 作业性能问题的常见原因。当某些 task 处理的数据量远大于其他 task 时，就会出现数据倾斜。解决方法包括：1) 加盐（salting）技术 2) 调整分区键 3) 使用两阶段聚合。
