# 知识块向量化超能力 - 执行计划

## 一、架构设计

### 1.1 整体架构
```
用户请求
    ↓
知识导入服务
    ↓
├─ 同步写入 MySQL（knowledge_chunks）─→ 立即返回用户
│   └─ 字段：id, content, doc_type, route_action, vectorize_status
│
└─ 异步向量化任务（提交到线程池）
    ↓
    调用阿里云 Embedding API
    ↓
    写入 PostgreSQL（knowledge_vectors）
    ↓
    更新 MySQL vectorize_status = 'SUCCESS'
```

### 1.2 数据流转
| 步骤 | 操作 | 数据库 | 是否阻塞用户 |
|-----|------|--------|------------|
| 1 | 保存原文 | MySQL | 是（<100ms） |
| 2 | 返回用户 | - | - |
| 3 | 调用 Embedding API | - | 否（后台执行） |
| 4 | 保存向量 | PostgreSQL | 否 |
| 5 | 更新状态 | MySQL | 否 |

### 1.3 技术栈
- **MySQL**: 存储原文 + 业务数据（MyBatis-Plus）
- **PostgreSQL + pgvector**: 向量存储 + 检索（Spring Data JPA）
- **阿里云 DashScope**: Embedding API（text-embedding-v3，1024 维）
- **Spring AI Alibaba**: Embedding 客户端封装
- **异步线程池**: 4 核心 / 8 最大 / 500 队列

@Repository
public interface KnowledgeVectorRepository extends JpaRepository<KnowledgeVector, Long> {
    
    // 向量检索：返回最相似的 top-k 个结果
    @Query(value = "SELECT chunk_id, doc_type, route_action, " +
           "1 - (embedding <=> CAST(:queryVector AS vector)) AS similarity " +
           "FROM knowledge_vectors " +
           "WHERE doc_type = :docType " +
           "ORDER BY embedding <=> CAST(:queryVector AS vector) " +
           "LIMIT :topK", nativeQuery = true)
    List<Object[]> findTopKSimilar(
        @Param("queryVector") String queryVector,  // 格式：[0.1,0.2,...]
        @Param("docType") String docType,
        @Param("topK") int topK
    );
}

### 第三阶段：知识导入服务 ⏳
**目标**：实现同步写入 + 异步向量化

#### 3.1 知识导入服务（`KnowledgeIngestionService.java`）
```java
@Service
@Slf4j
public class KnowledgeIngestionService {
    
    @Autowired
    private KnowledgeChunkMapper chunkMapper;
    
    @Autowired
    private KnowledgeVectorRepository vectorRepository;
    
    @Autowired
    private EmbeddingService embeddingService;
    
    @Autowired
    @Qualifier("vectorizationExecutor")
    private Executor vectorizationExecutor;
    
    /**
     * 导入知识块（主流程）
     * 1. 同步写入 MySQL
     * 2. 异步向量化
     */
    @Transactional(rollbackFor = Exception.class)
    public Long importKnowledge(String content, String docType, String routeAction) {
        // 1. 保存原文到 MySQL
        KnowledgeChunk chunk = new KnowledgeChunk();
        chunk.setContent(content);
        chunk.setDocType(docType);
        chunk.setRouteAction(routeAction);
        chunk.setVectorizeStatus("PENDING");
        chunk.setCreatedAt(LocalDateTime.now());
        chunk.setUpdatedAt(LocalDateTime.now());
        
        chunkMapper.insert(chunk);
        Long chunkId = chunk.getId();
        
        log.info("知识块已保存到 MySQL: chunkId={}", chunkId);
        
        // 2. 提交异步向量化任务
        vectorizationExecutor.execute(() -> vectorizeChunk(chunkId, content, docType, routeAction));
        
        return chunkId;
    }
    
    /**
     * 向量化任务（后台执行）
     */
    private void vectorizeChunk(Long chunkId, String content, String docType, String routeAction) {
        try {
            // 调用 Embedding API
            float[] embedding = embeddingService.embedDocument(content);
            
            // 转换为 pgvector 格式：[0.1,0.2,...]
            String vectorString = Arrays.stream(embedding)
                .mapToObj(String::valueOf)
                .collect(Collectors.joining(",", "[", "]"));
            
            // 保存到 PostgreSQL
            KnowledgeVector vector = new KnowledgeVector();
            vector.setChunkId(chunkId);
            vector.setEmbedding(vectorString);
            vector.setDocType(docType);
            vector.setRouteAction(routeAction);
            vector.setCreatedAt(LocalDateTime.now());
            vector.setUpdatedAt(LocalDateTime.now());
            
            vectorRepository.save(vector);
            
            // 更新 MySQL 状态为 SUCCESS
            chunkMapper.updateById(KnowledgeChunk.builder()
                .id(chunkId)
                .vectorizeStatus("SUCCESS")
                .updatedAt(LocalDateTime.now())
                .build());
            
            log.info("向量化成功: chunkId={}, embedding_dim={}", chunkId, embedding.length);
            
        } catch (Exception e) {
            log.error("向量化失败: chunkId={}, error={}", chunkId, e.getMessage(), e);
            
            // 更新 MySQL 状态为 FAILED
            chunkMapper.updateById(KnowledgeChunk.builder()
                .id(chunkId)
                .vectorizeStatus("FAILED")
                .errorMessage(e.getMessage())
                .updatedAt(LocalDateTime.now())
                .build());
        }
    }
}
```

### 第四阶段：向量检索服务 ⏳
**目标**：实现语义搜索

#### 4.1 向量检索服务（`KnowledgeSearchService.java`）
```java
@Service
@Slf4j
public class KnowledgeSearchService {
    
    @Autowired
    private KnowledgeVectorRepository vectorRepository;
    
    @Autowired
    private KnowledgeChunkMapper chunkMapper;
    
    @Autowired
    private EmbeddingService embeddingService;
    
    /**
     * 语义搜索
     * @param query 用户查询
     * @param docType 文档类型过滤
     * @param topK 返回前 K 个结果
     * @return 相似知识块列表
     */
    public List<SearchResult> search(String query, String docType, int topK) {
        // 1. 将查询文本向量化
        float[] queryEmbedding = embeddingService.embedQuery(query);
        
        String queryVector = Arrays.stream(queryEmbedding)
            .mapToObj(String::valueOf)
            .collect(Collectors.joining(",", "[", "]"));
        
        // 2. 在 PostgreSQL 中检索最相似的向量
        List<Object[]> results = vectorRepository.findTopKSimilar(queryVector, docType, topK);
        
        // 3. 根据 chunk_id 查询 MySQL 获取原文
        List<Long> chunkIds = results.stream()
            .map(row -> ((Number) row[0]).longValue())
            .collect(Collectors.toList());
        
        if (chunkIds.isEmpty()) {
            return Collections.emptyList();
        }
        
        Map<Long, KnowledgeChunk> chunkMap = chunkMapper.selectBatchIds(chunkIds)
            .stream()
            .collect(Collectors.toMap(KnowledgeChunk::getId, chunk -> chunk));
        
        // 4. 组装返回结果
        return results.stream().map(row -> {
            Long chunkId = ((Number) row[0]).longValue();
            String resultDocType = (String) row[1];
            String routeAction = (String) row[2];
            Double similarity = ((Number) row[3]).doubleValue();
            
            KnowledgeChunk chunk = chunkMap.get(chunkId);
            
            return SearchResult.builder()
                .chunkId(chunkId)
                .content(chunk != null ? chunk.getContent() : null)
                .docType(resultDocType)
                .routeAction(routeAction)
                .similarity(similarity)
                .build();
        }).collect(Collectors.toList());
    }
}

@Data
@Builder
class SearchResult {
    private Long chunkId;
    private String content;
    private String docType;
    private String routeAction;
    private Double similarity;  // 相似度得分（0-1）
}
```

### 第五阶段：断点重跑机制 ⏳
**目标**：处理向量化失败的数据

#### 5.1 断点重跑服务（`VectorizationRetryService.java`）
```java
@Service
@Slf4j
public class VectorizationRetryService {
    
    @Autowired
    private KnowledgeChunkMapper chunkMapper;
    
    @Autowired
    private KnowledgeIngestionService ingestionService;
    
    /**
     * 重试所有 PENDING 状态的数据
     */
    public void retryPendingChunks(int batchSize) {
        List<KnowledgeChunk> pendingChunks = chunkMapper.findPendingChunks(batchSize);
        
        log.info("开始重试 PENDING 数据: count={}", pendingChunks.size());
        
        pendingChunks.forEach(chunk -> {
            ingestionService.vectorizeChunk(
                chunk.getId(),
                chunk.getContent(),
                chunk.getDocType(),
                chunk.getRouteAction()
            );
        });
    }
    
    /**
     * 重试所有 FAILED 状态的数据
     */
    public void retryFailedChunks(int batchSize) {
        List<KnowledgeChunk> failedChunks = chunkMapper.findFailedChunks(batchSize);
        
        log.info("开始重试 FAILED 数据: count={}", failedChunks.size());
        
        failedChunks.forEach(chunk -> {
            // 重置状态为 PENDING
            chunk.setVectorizeStatus("PENDING");
            chunk.setErrorMessage(null);
            chunkMapper.updateById(chunk);
            
            // 提交向量化任务
            ingestionService.vectorizeChunk(
                chunk.getId(),
                chunk.getContent(),
                chunk.getDocType(),
                chunk.getRouteAction()
            );
        });
    }
}
```

#### 5.2 定时任务（`VectorizationScheduler.java`）
```java
@Component
@Slf4j
@EnableScheduling
public class VectorizationScheduler {
    
    @Autowired
    private VectorizationRetryService retryService;
    
    /**
     * 每 5 分钟检查一次 PENDING 数据
     */
    @Scheduled(fixedDelay = 300000)
    public void retryPendingTask() {
        retryService.retryPendingChunks(100);
    }
    
    /**
     * 每小时重试一次 FAILED 数据
     */
    @Scheduled(fixedDelay = 3600000)
    public void retryFailedTask() {
        retryService.retryFailedChunks(50);
    }
}
```

## 四、风险与应对

| 风险 | 影响 | 应对措施 |
|-----|------|---------|
| Embedding API 限流 | 向量化失败率高 | 降低并发数 + 指数退避重试 |
| PostgreSQL 连接池耗尽 | 写入/查询失败 | 增加连接池大小 + 监控 |
| 向量化延迟高 | 用户等待时间长 | 异步化 + 状态查询接口 |
| pgvector 索引构建慢 | 导入大数据时卡顿 | 先禁用索引 → 批量导入 → 重建索引 |
