# 基础设施搭建指南

## ✅ 已完成配置

### 1. 依赖管理（pom.xml）
- PostgreSQL 驱动
- Spring Data JPA（与 MyBatis-Plus 共存）
- Spring AI Alibaba Embedding

### 2. 多数据源配置
- **MySQL 数据源**（主，MyBatis-Plus）：业务表 + knowledge_chunks
- **PostgreSQL 数据源**（JPA）：pgvector 向量检索

### 3. 核心组件
- `DataSourceConfig.java`: 多数据源配置类
- `VectorizationConfig.java`: 向量化线程池（4核心/8最大/500队列）
- `EmbeddingService.java`: 阿里云 Embedding API 封装

### 4. 数据库表结构
- **MySQL**: `knowledge_chunks`（Flyway 自动创建）
- **PostgreSQL**: `knowledge_vectors` + HNSW 索引（已手动创建）

### 5. 验证结果

  }
